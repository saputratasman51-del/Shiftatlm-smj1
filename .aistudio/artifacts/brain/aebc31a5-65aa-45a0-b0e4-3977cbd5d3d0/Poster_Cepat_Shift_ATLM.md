# CARA CEPAT MENGGUNAKAN SHIFT ATLM
## RSUD Sultan Muhammad Jamaludin I

1.  **Buka Aplikasi:** Akses https://shiftatlm-smj1.vercel.app/petugas
2.  **Login:** Masukkan NIP/Username & Password.
3.  **Pilih Menu:** Gunakan dashboard untuk jadwal hari ini.
4.  **Serah Terima:** Pilih menu "Serah Terima" > Tambah Baru > Isi data > Kirim.
5.  **Periksa Data:** Gunakan menu "Riwayat" untuk memastikan data tersimpan.
6.  **Logout:** Klik profil > Logout setelah selesai (terutama di perangkat bersama).
